This file lists the license and copyright of mlw-xsheet itself and of every third-party component it
uses or ships: the Python packages installed in its Docker image, the browser libraries bundled with
NiceGUI, fonts, container base images, and third-party material in the repository.

Generated on 2026-09-25 from the v1.0.0 release (commit 4d38308) and its production Docker image.
Python dependency versions are the ones that image installed: requirements.txt gives minimum
versions, so a later build may pick up newer releases with the same licenses.

This is a best-effort inventory, not legal advice. Each component's own license file is
authoritative.

8. Notes on copyleft licenses
====================================================================================================

  fpdf2 (LGPL-3.0-only)
    mlw-xsheet uses fpdf2 unmodified, as a separately installed Python library that users can
    replace with another version, which the LGPL permits. Its license text is installed with the
    package in the image, and its source is available from https://github.com/py-pdf/fpdf2.
    Modifying fpdf2 itself would require releasing those changes under the LGPL.

  MPL-2.0 (bidict, certifi; orjson in part; DOMPurify as an option)
    The Mozilla Public License applies file by file. These components are used unmodified and their
    source is available from their projects; changes to their files would have to be shared under
    the MPL.

  docutils (installed as a NiceGUI dependency)
    Most of docutils is in the public domain or under BSD-2-Clause; a few optional parts are under
    the GPL. mlw-xsheet does not use docutils directly.

  Debian and Alpine packages in the container images
    Include GPL and LGPL software, used unmodified. Source is available from the Debian and Alpine
    projects; per-package terms are in the images.
